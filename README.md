# CRUD
Http-сервер на Rust, поддерживающий слудующие методы: 
 - POST /create_event - для создания мероприятия необходимо передать следующие данные в формате JSON: start_time и end_time в формате YYYY-mm-DDTHH:MM:SSZ, name - длина до 255 символов, description - длина до 1000 символов.
 - POST /update_event - все то же самое, что и для создания, но еще и id - целочисленное значение больше 0.
 - POST /delete_event - для удаления передать в формате JSON id мероприятия, большее 0.
 - GET /events_for_day - получение событий на день, в качестве параметра передать curr_time в формате YYYY-mm-DDTHH:MM:SSZ, относительно того дня, для которого необходимо получить данные (параметр аналогичен для остальных GET-запросов).
 - GET /events_for_week - получение события на указанную неделю.
 - GET /events_for_month - получение события на указанный месяц.

Данные для подключения к базе данных и изначальные настройки сервера указаны в файле .env. Формат представления информации для базы данных указан в файле DataBase.sql, в качестве бд используется PostgreSQL. При работе с событиями используется кеширование.
